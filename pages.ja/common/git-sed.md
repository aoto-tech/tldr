# git sed

> Git管理下のファイル内のパターンをsedで置換する。
> `git-extras` の一部。
> 詳細情報: <https://manned.org/git-sed>。

- 現在のリポジトリ内にある指定したテキストを置換する:

`git sed '{{検索文字列}}' '{{置換文字列}}'`

- 指定したテキストを置換し、標準のコミットメッセージで変更をコミットする:

`git sed -c '{{検索文字列}}' '{{置換文字列}}'`

- 正規表現を使用して指定したテキストを置換する:

`git sed -f g '{{検索文字列}}' '{{置換文字列}}'`

- 指定したディレクトリ以下のすべてのファイル内にある指定したテキストを置換する:

`git sed '{{検索文字列}}' '{{置換文字列}}' -- {{ディレクトリ/サブディレクトリ}}`
