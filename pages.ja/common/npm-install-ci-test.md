# npm install-ci-test

> 単一のコマンドでプロジェクトの依存関係をインストールし、テストを実行します。主に継続的インテグレーション (CI) 環境で使用されます。
> `npm ci && npm test` を実行するのと同じです。
> 詳細情報: <https://docs.npmjs.com/cli/install-ci-test/>。

- 依存関係をインストールし、テストを実行します:

`npm {{[cit|install-ci-test]}}`

- インストールおよびテスト中に詳細なログを表示します:

`npm {{[cit|install-ci-test]}} --verbose`
