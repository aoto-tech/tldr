# git branch

> ブランチを操作するための主要なGitコマンド。
> 詳細情報: <https://git-scm.com/docs/git-branch>。

- すべてのブランチを一覧表示する (ローカルおよびリモート。現在のブランチは `*` で強調表示される):

`git branch {{[-a|--all]}}`

- 指定したGitコミットを履歴に含むブランチを一覧表示する:

`git branch {{[-a|--all]}} --contains {{コミットハッシュ}}`

- 現在のブランチ名を表示する:

`git branch --show-current`

- 現在のコミットを基に新しいブランチを作成する:

`git branch {{ブランチ名}}`

- 指定したコミットを基に新しいブランチを作成する:

`git branch {{ブランチ名}} {{コミットハッシュ}}`

- ブランチ名を変更する (実行する前に別のブランチへ切り替える必要がある):

`git branch {{[-m|--move]}} {{古いブランチ名}} {{新しいブランチ名}}`

- ローカルブランチを削除する (実行する前に別のブランチへ切り替える必要がある):

`git branch {{[-d|--delete]}} {{ブランチ名}}`

- リモートブランチを削除する:

`git push {{リモート名}} {{[-d|--delete]}} {{リモートブランチ名}}`
