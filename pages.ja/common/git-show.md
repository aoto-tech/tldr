# git show

> さまざまな種類のGitオブジェクト (コミット、タグなど) を表示する。
> 詳細情報: <https://git-scm.com/docs/git-show>。

- 最新のコミットに関する情報 (ハッシュ、メッセージ、変更、その他のメタデータ) を表示する:

`git show`

- 指定したコミット、タグ、またはブランチに関する情報を表示する (最新のコミットを表す `HEAD` など):

`git show {{コミット|タグ|ブランチ}}`

- 追加、名前変更、または削除されたファイルの一覧のみを表示する:

`git show --summary {{コミット}}`

- 行を比較するときに空白を無視する:

`git show {{[-w|--ignore-all-space]}}`

- 差分出力を抑制し、コミットメッセージを1行で表示する:

`git show --oneline {{[-s|--no-patch]}} {{コミット}}`

- 変更されたファイルの統計 (追加および削除された文字数) のみを表示する:

`git show --stat {{コミット}}`

- コミットで変更されたすべてのファイル (変更、追加、削除) の簡略化された一覧を表示する:

`git show --name-only {{コミット}}`

- 指定したリビジョン (ブランチ、タグ、コミットなど) におけるファイルの内容を表示する:

`git show {{リビジョン}}:{{ファイルへのパス}}`
