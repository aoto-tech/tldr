# npm completion

> npm コマンドのタブ補完を有効化または設定します。
> 詳細情報: <https://docs.npmjs.com/cli/npm-completion/>。

- 現在のシェル セッションのタブ補完を有効にします:

`npm completion`

- シェル プロファイルに補完を追加します (Bash):

`npm completion >> ~/.bashrc`

- シェル プロファイル (Zsh) に補完を追加します:

`npm completion >> ~/.zshrc`

- 完了スクリプトを特定のファイルに書き込みます:

`npm completion > {{path/to/file}}`
