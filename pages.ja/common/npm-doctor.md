# npm doctor

> npm 環境の健全性を確認します。
> 詳細情報: <https://docs.npmjs.com/cli/npm-doctor/>。

- `npm` のすべてのデフォルトのヘルスチェックを実行します:

`npm doctor`

- `npm` レジストリへの接続を確認します:

`npm doctor connection`

- 使用している Node.js と `npm` のバージョンを確認します:

`npm doctor versions`

- `npm` ディレクトリとキャッシュの権限の問題を確認します:

`npm doctor permissions`

- キャッシュされたパッケージ ファイルとチェックサムを検証します:

`npm doctor cache`
