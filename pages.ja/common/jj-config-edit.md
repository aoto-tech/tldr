# jj config edit

> 構成ファイルでエディタを起動します。
> `jj config path` も参照してください。
> 詳細情報: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-config-edit>。

- ユーザーレベルの構成ファイルでエディタを起動します:

`jj config {{[e|edit]}} --user`

- リポジトリレベルの構成ファイルでエディタを起動します:

`jj config {{[e|edit]}} --repo`

- ワークスペースレベルの構成ファイルでエディタを起動します:

`jj config {{[e|edit]}} --workspace`
