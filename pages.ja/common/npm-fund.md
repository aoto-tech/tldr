# npm fund

> パッケージから資金調達情報を取得します。
> 詳細情報: <https://docs.npmjs.com/cli/npm-fund/>。

- 現在のディレクトリ内のプロジェクトの資金提供 URL を含む依存関係を一覧表示します:

`npm fund`

- デフォルトの Web ブラウザで特定のパッケージのファンディング URL を開きます:

`npm fund {{package}}`

- 現在のディレクトリ内のプロジェクトの特定のワークスペースの依存関係をファンディング URL とともにリストします:

`npm fund {{[-w|--workspace]}} {{workspace}}`
