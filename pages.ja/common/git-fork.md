# git fork

> GitHubリポジトリをフォークする。`git clone` と同様だが、先にフォークを作成する。
> `git-extras` の一部。
> 詳細情報: <https://github.com/tj/git-extras/blob/main/Commands.md#git-fork>。

- URLを指定してGitHubリポジトリをフォークし、クローンする:

`git fork {{https://github.com/tldr-pages/tldr}}`

- スラッグを指定してGitHubリポジトリをフォークし、クローンする:

`git fork {{tldr-pages/tldr}}`
