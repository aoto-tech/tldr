# npm stars

> お気に入りとしてマークされたパッケージを表示します。
> 詳細情報: <https://docs.npmjs.com/cli/v11/npm-stars>。

- 現在ログインしているユーザーごとにスター付きパッケージをすべて表示します:

`npm stars`

- 特定のレジストリからスター付きパッケージを表示します:

`npm stars --registry {{registry_url}}`

- 特定のユーザーがスターを付けたパッケージを表示します:

`npm stars {{username}}`

- 特定のレジストリから特定のユーザーがスターを付けたパッケージを表示します:

`npm stars {{username}} --registry {{registry_url}}`

- ヘルプを表示する:

`npm stars {{[-h|--help]}}`
