# git create-branch

> リポジトリにGitブランチを作成する。
> `git-extras` の一部。
> 詳細情報: <https://manned.org/git-create-branch>。

- ローカルブランチを作成する:

`git create-branch {{ブランチ名}}`

- ローカルとoriginにブランチを作成する:

`git create-branch {{[-r|--remote]}} {{ブランチ名}}`

- ローカルと上流にブランチを作成する (フォーク経由):

`git create-branch {{[-r|--remote]}} upstream {{ブランチ名}}`
