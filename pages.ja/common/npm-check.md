# npm-check

> 古い、間違っている、未使用の npm パッケージの依存関係を確認します。
> 詳細情報: <https://github.com/dylang/npm-check>。

- 古くなった、間違った、未使用の依存関係のレポートを表示します:

`npm-check`

- 古いパッケージを対話的に更新します:

`npm-check {{[-u|--update]}}`

- プロンプトを表示せずにすべてを更新します:

`npm-check {{[-y|--update-all]}}`

- 未使用のパッケージをチェックしないでください:

`npm-check {{[-s|--skip-unused]}}`
