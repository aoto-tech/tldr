# npm update

> 現在のプロジェクトのパッケージを更新します。
> 詳細情報: <https://docs.npmjs.com/cli/npm-update/>。

- 現在のプロジェクト内のすべてのパッケージを更新します:

`npm {{[up|update]}}`

- 現在のプロジェクト内の特定のパッケージを更新します:

`npm {{[up|update]}} {{package}}`

- パッケージをグローバルに更新します:

`npm {{[up|update]}} {{package}} {{[-g|--global]}}`

- 複数のパッケージを一度に更新します:

`npm {{[up|update]}} {{package1 package2 ...}}`
