# jj config path

> 構成ファイルへのパスを出力します。
> `jj config edit` も参照してください。
> 詳細情報: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-config-path>。

- ユーザーレベルの設定ファイルへのパスを出力します:

`jj config {{[p|path]}} --user`

- リポジトリレベルの構成ファイルへのパスを出力します:

`jj config {{[p|path]}} --repo`

- ワークスペースレベルの構成ファイルへのパスを出力します:

`jj config {{[p|path]}} --workspace`
