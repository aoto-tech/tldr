# npm ls

> インストールされたパッケージを `stdout` に出力します。
> 詳細情報: <https://docs.npmjs.com/cli/npm-ls/>。

- 現在のプロジェクト内の直接依存関係のすべてのバージョンを `stdout` に出力します:

`npm {{[ls|list]}}`

- ピアの依存関係を含む、インストールされているすべてのパッケージを出力します:

`npm {{[ls|list]}} {{[-a|--all]}}`

- グローバルにインストールされているすべてのパッケージを出力します:

`npm {{[ls|list]}} {{[-g|--global]}}`

- 依存関係を拡張情報とともに出力します:

`npm {{[ls|list]}} {{[-l|--long]}}`

- 依存関係を解析可能な形式で出力します:

`npm {{[ls|list]}} {{[-p|--parseable]}}`

- 依存関係を JSON 形式で出力します:

`npm {{[ls|list]}} --json`
