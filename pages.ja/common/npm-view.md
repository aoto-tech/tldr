# npm view

> パッケージに関するレジストリ情報を表示します。
> 詳細情報: <https://docs.npmjs.com/cli/npm-view/>。

- パッケージの最新バージョンに関する情報を表示します:

`npm {{[v|view]}} {{package}}`

- パッケージの特定のバージョンに関する情報を表示します:

`npm {{[v|view]}} {{package}}@{{version}}`

- パッケージの利用可能なすべてのバージョンを表示します:

`npm {{[v|view]}} {{package}} versions`

- パッケージの説明を表示します:

`npm {{[v|view]}} {{package}} description`

- パッケージの最新バージョンの依存関係を表示します:

`npm {{[v|view]}} {{package}} dependencies`

- パッケージのリポジトリ URL を表示します:

`npm {{[v|view]}} {{package}} repository`

- パッケージのメンテナを表示します:

`npm {{[v|view]}} {{package}} maintainers`
