# git effort

> ファイルごとのコミット数と「活動日数」(ファイルに貢献があった日の総数) を表示し、ファイルの活動量を確認する。
> `git-extras` の一部。
> 詳細情報: <https://github.com/tj/git-extras/blob/main/Commands.md#git-effort>。

- リポジトリ内の各ファイルについて、コミット数と活動日数を表示する:

`git effort`

- 指定した数以上のコミットで変更されたファイルについて、コミット数と活動日数を表示する:

`git effort --above {{5}}`

- 指定した作成者が変更したファイルについて、コミット数と活動日数を表示する:

`git effort -- --author="{{ユーザー名}}"`

- 指定した時刻または日付以降に変更されたファイルについて、コミット数と活動日数を表示する:

`git effort -- --since="{{last month}}"`

- 指定したファイルまたはディレクトリだけについて、コミット数と活動日数を表示する:

`git effort {{ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ1 ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ2 ...}}`

- 指定したディレクトリ内のすべてのファイルについて、コミット数と活動日数を表示する:

`git effort {{ディレクトリ/サブディレクトリ/*}}`
