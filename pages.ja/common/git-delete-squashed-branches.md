# git delete-squashed-branches

> 指定したブランチにスカッシュマージされたブランチを削除し、指定したブランチをチェックアウトする。ブランチを省略した場合、現在チェックアウトしているブランチを使用する。
> `git-extras` の一部。
> 詳細情報: <https://github.com/tj/git-extras/blob/main/Commands.md#git-delete-squashed-branches>。

- 現在チェックアウトしているブランチにスカッシュマージされたすべてのブランチを削除する:

`git delete-squashed-branches`

- 指定したブランチにスカッシュマージされたすべてのブランチを削除する:

`git delete-squashed-branches {{ブランチ名}}`
