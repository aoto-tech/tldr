# npm run

> スクリプトを実行します。
> 詳細情報: <https://docs.npmjs.com/cli/npm-run/>。

- 利用可能なスクリプトをリストします:

`npm run`

- スクリプトを実行します:

`npm run {{script_name}}`

- 引数をスクリプトに渡します:

`npm run {{script_name}} -- {{argument}} {{--option}}`

- `start` という名前のスクリプトを実行します:

`npm start`

- `stop` という名前のスクリプトを実行します:

`npm stop`

- `restart` という名前のスクリプトを実行します:

`npm restart`

- `test` という名前のスクリプトを実行します:

`npm {{[t|test]}}`
