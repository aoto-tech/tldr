# git rscp

> `git scp` の逆操作。リモートリポジトリの作業ディレクトリから現在の作業ツリーへファイルをコピーする。
> `git-extras` の一部。
> 詳細情報: <https://github.com/tj/git-extras/blob/main/Commands.md#git-scp>。

- 指定したファイルをリモートからコピーする:

`git rscp {{リモート名}} {{ディレクトリ/サブディレクトリ/ファイル1 ディレクトリ/サブディレクトリ/ファイル2 ...}}`

- 指定したディレクトリをリモートからコピーする:

`git rscp {{リモート名}} {{ディレクトリ/サブディレクトリ}}`
