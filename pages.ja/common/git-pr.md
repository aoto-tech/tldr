# git pr

> GitHubのプルリクエストをローカルにチェックアウトする。
> `git-extras` の一部。
> 詳細情報: <https://github.com/tj/git-extras/blob/main/Commands.md#git-pr>。

- 指定したプルリクエストをチェックアウトする:

`git pr {{プルリクエスト番号}}`

- 指定したリモートからプルリクエストをチェックアウトする:

`git pr {{プルリクエスト番号}} {{リモート}}`

- URLからプルリクエストをチェックアウトする:

`git pr {{URL}}`

- 古いプルリクエストのブランチを消去する:

`git pr clean`
