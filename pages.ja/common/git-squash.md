# git squash

> 複数のコミットを1つのコミットにまとめる。
> `git-extras` の一部。
> 詳細情報: <https://manned.org/git-squash>。

- 指定したブランチのすべてのコミットを1つのコミットとして現在のブランチへマージする:

`git squash {{元のブランチ}}`

- 現在のブランチで指定したコミット以降のすべてのコミットをまとめる:

`git squash {{コミット}}`

- 直近 `n` 個のコミットをまとめ、メッセージを指定してコミットする:

`git squash HEAD~{{n}} "{{メッセージ}}"`

- 直近 `n` 個のコミットをまとめ、各コミットのメッセージを連結してコミットする:

`git squash --squash-msg HEAD~{{n}}`
