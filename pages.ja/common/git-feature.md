# git feature

> 機能ブランチを作成またはマージする。
> 機能ブランチは `feature/名前` 形式に従う。
> 詳細情報: <https://manned.org/git-feature>。

- 新しい機能ブランチを作成して切り替える:

`git feature {{機能ブランチ}}`

- 機能ブランチを現在のブランチへマージし、マージコミットを作成する:

`git feature finish {{機能ブランチ}}`

- 機能ブランチを現在のブランチへマージし、変更を1つのコミットにまとめる:

`git feature finish --squash {{機能ブランチ}}`

- 指定した機能ブランチの変更を対応するリモートブランチへ送信する:

`git feature {{機能ブランチ}} {{[-r|--remote]}} {{リモート名}}`
