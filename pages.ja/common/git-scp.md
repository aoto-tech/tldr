# git scp

> 現在の作業ツリーからリモートリポジトリの作業ディレクトリへファイルをコピーする。
> `git-extras` の一部。ファイルの転送には `rsync` を使用する。
> 詳細情報: <https://github.com/tj/git-extras/blob/main/Commands.md#git-scp>。

- ステージされていないファイルを指定したリモートへコピーする:

`git scp {{リモート名}}`

- ステージ済みと未ステージのファイルをリモートへコピーする:

`git scp {{リモート名}} HEAD`

- 直前のコミットで変更されたファイルと、ステージ済みまたは未ステージのファイルをリモートへコピーする:

`git scp {{リモート名}} HEAD~1`

- 指定したファイルをリモートへコピーする:

`git scp {{リモート名}} {{ディレクトリ/サブディレクトリ/ファイル1 ディレクトリ/サブディレクトリ/ファイル2 ...}}`

- 指定したディレクトリをリモートへコピーする:

`git scp {{リモート名}} {{ディレクトリ/サブディレクトリ}}`
