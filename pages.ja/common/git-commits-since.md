# git commits-since

> 指定した時刻または日付以降のコミットを表示する。
> `git-extras` の一部。
> 詳細情報: <https://github.com/tj/git-extras/blob/main/Commands.md#git-commits-since>。

- 昨日以降のコミットを表示する:

`git commits-since {{yesterday}}`

- 先週以降のコミットを表示する:

`git commits-since {{last week}}`

- 先月以降のコミットを表示する:

`git commits-since {{last month}}`

- 昨日の午後2時以降のコミットを表示する:

`git commits-since {{yesterday 2pm}}`
