# jj config unset

> 構成オプションの設定を解除します。
> `jj config set` も参照してください。
> 詳細情報: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-config-unset>。

- ユーザーレベルの設定で設定オプションの設定を解除します:

`jj config {{[u|unset]}} --user {{name}}`

- リポジトリレベルの構成で構成オプションの設定を解除します:

`jj config {{[u|unset]}} --repo {{name}}`

- ワークスペースレベルの構成で構成オプションの設定を解除します:

`jj config {{[u|unset]}} --workspace {{name}}`
