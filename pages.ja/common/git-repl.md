# git repl

> Git REPL (read-evaluate-print loop)。対話式のGitシェル。
> `git-extras` の一部。
> 詳細情報: <https://github.com/tj/git-extras/blob/main/Commands.md#git-repl>。

- 対話式のGitシェルを開始する:

`git repl`

- 対話式のGitシェル内でGitコマンドを実行する:

`{{Gitサブコマンド}} {{コマンドの引数}}`

- 対話式のGitシェル内で外部コマンド (Git以外) を実行する:

`!{{コマンド}} {{コマンドの引数}}`

- 対話式のGitシェルを終了する (または `<Ctrl d>` を押す):

`exit`
