# npm-home

> Web ブラウザーで、パッケージの `npm` ページ、Yarn ページ、または GitHub リポジトリを開きます。
> 詳細情報: <https://github.com/sindresorhus/npm-home>。

- Web ブラウザで特定のパッケージの `npm` ページを開きます:

`npm-home {{package}}`

- Web ブラウザで特定のパッケージの GitHub リポジトリを開きます:

`npm-home {{[-g|--github]}} {{package}}`

- Web ブラウザで特定のパッケージの Yarn ページを開きます:

`npm-home {{[-y|--yarn]}} {{package}}`
