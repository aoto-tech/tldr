# git annex

> ファイルの内容をチェックインせずにGitで管理する。
> ファイルをannexへ追加すると、その内容はキー・バリューストアへ移動され、内容を指すシンボリックリンクが作成される。
> 詳細情報: <https://git-annex.branchable.com/git-annex/>。

- Git annexを使用するリポジトリを初期化する:

`git annex init`

- ファイルを追加する:

`git annex add {{ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ}}`

- ファイルまたはディレクトリの現在の状態を表示する:

`git annex status {{ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ}}`

- ローカルリポジトリをリモートと同期する:

`git annex {{リモート}}`

- ファイルまたはディレクトリを取得する:

`git annex get {{ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ}}`

- ヘルプを表示する:

`git annex help`
