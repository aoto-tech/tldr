# npm link

> ローカル パッケージをグローバル `node_modules` または開発用の別のプロジェクトにシンボリックリンクします。
> 詳細情報: <https://docs.npmjs.com/cli/npm-link/>。

- 現在のパッケージをグローバルにシンボリックリンクします:

`npm {{[ln|link]}}`

- グローバルにリンクされたパッケージを別のプロジェクトの `node_modules` にリンクします:

`npm {{[ln|link]}} {{package_name}}`

- 現在のプロジェクトからパッケージのリンクを解除します:

`npm {{[r|unlink]}} {{package_name}}`
