# git reset-file

> ファイルを `HEAD` または指定したコミットの状態へ戻す。
> `git-extras` の一部。
> 詳細情報: <https://github.com/tj/git-extras/blob/main/Commands.md#git-reset-file>。

- ファイルを `HEAD` の状態へリセットする:

`git reset-file {{ディレクトリ/サブディレクトリ/ファイル}}`

- ファイルを指定したコミットの状態へリセットする:

`git reset-file {{ディレクトリ/サブディレクトリ/ファイル}} {{コミットハッシュ}}`
