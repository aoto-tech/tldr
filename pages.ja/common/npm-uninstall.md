# npm uninstall

> パッケージを削除します。
> 詳細情報: <https://docs.npmjs.com/cli/npm-uninstall/>。

- 現在のプロジェクトからパッケージを削除します:

`npm {{[r|uninstall]}} {{package_name}}`

- パッケージをグローバルに削除します:

`npm {{[r|uninstall]}} {{package_name}} {{[-g|--global]}}`

- 複数のパッケージを一度に削除します:

`npm {{[r|uninstall]}} {{package_name1 package_name2 ...}}`
